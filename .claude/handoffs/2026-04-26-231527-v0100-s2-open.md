## Key Patterns Discovered

**Tree-content checkpoint after `--no-ff` merge.** The single most important procedural lesson from this session. After every stage merge ceremony, before push, verify the merge commit's tree carries the expected content via `git diff main^1 main --stat` and `git ls-tree -r HEAD <expected-path>`. Surface-level signals (the prompt clearing from `MERGING`, `git status` reporting clean, the merge commit appearing with two parents in `git log`) can all pass simultaneously while the merge tree equals the first parent (i.e., none of the second parent's content landed). The S1 close shipped exactly such an empty merge; recovery cost a cherry-pick and a tag force-move.

**In-place stage branches rather than worktrees.** Strategy section 4.1 specifies `git worktree add ../co-author-harness-S<N>` for per-stage isolation. Cowork file-tool scope is `B:\Agents\co-author-harness\` only — sibling worktrees are not file-tool-accessible. S1 deviated to in-place stage branches (`stage/v0.10.0-S<N>` on the existing checkout); S1.5 followed the same pattern. The eight-stage sequence is linear by design, so the worktree pattern's parallel-work benefit is not lost; per-stage tags preserve rollback granularity.

**Strategy's `(unreleased)` CHANGELOG pattern requires a script-side fix.** Strategy section 8.2 authorises a `## v0.10.0 (unreleased)` accumulation heading at the top of CHANGELOG.md throughout the rollout; strategy section 8.4 defers the manifest version bump to the RC gate. Without a script-side fix, every stage close trips `version-check.py` with a spurious BLOCKER. S1.5 patched `extract_changelog_latest_version()` to skip `(unreleased)` headings; documented in release notes section 2.S1.5 and CHANGELOG v0.10.0 (unreleased) bullet.

**`plugin_calibrator` invocation requires PYTHONPATH.** The unified-superkit's calibrator package lives in the plugin's installation directory rather than on the system Python path. PowerShell host-side invocation:

```

python -c "from plugin_calibrator.efficiency import audit_plugin, write_report; from pathlib import Path; r = audit_plugin(Path.cwd().resolve()); write_report(Path.cwd().resolve(), r)"
```

The CLI form (`python -m plugin_calibrator.efficiency`) is broken upstream per `RELEASE_NOTES_v0.9.0_addendum.md section Method`. Memory record: `reference_calibrator_invocation_workaround.md`.
