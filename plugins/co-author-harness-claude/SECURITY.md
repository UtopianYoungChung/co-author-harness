# Security Policy

This is a local research-writing harness and plugin repository. Do not publish credentials, private transcript material, unpublished research claims, or identifiable participant data in issues, commits, logs, releases, or generated artifacts.

Report security or privacy concerns directly to the repository owner at jo.chung@utoronto.ca. Include the affected path, the observed behavior, and the minimum evidence needed to reproduce or verify the concern.

Before release or distribution, run the repository checks listed in `AGENTS.md` and inspect generated packages for private data, secrets, and unintended workspace paths.
