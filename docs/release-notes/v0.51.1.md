# v0.51.1 maintenance release

Form-value diagnostics now respect fenced field boundaries and report stable field and original line locators. Malformed boundaries fail visibly. Metadata no longer creates sentences spanning multiple fields, while long or unclear prose inside a field still receives its normal review findings. The mode is opt-in with `--form-values`.

The Windows fixture-owner smoke test now expects the controller's existing refusal to detach a worker when its enclosing Job disallows breakaway.

The scholarly-evaluation fixture now uses a finite 1,500-second tree-inclusive timeout with a two-second cleanup reserve, sized from a 1,192.785-second supervised diagnostic with about 25% headroom; that diagnostic is not release qualification.

The ordinary task workflow documents bounded revision execution: resolve the authorized native or external route before provider preparation; bind a configured runtime once; read applicable instructions within explicit budgets; query tools and evidence by semantic names and schema; preserve allowed bytes and reject stale inputs; record actual actors, recovery status and measurable stages. The existing fast and coordinator lanes retain their respective review and lifecycle boundaries.

This release changes no model or provider pins, citation clearance requirements, host safety policy or research direction. It includes public harness code and instructions. Private application fixtures, scholarly sources, task-specific runners and local deployment evidence are excluded.

Apply the package through the registered marketplace or the verified commit-bound archive. Existing host sessions may retain their previous plugin snapshot until restarted; installation parity and runtime verification are reported separately in the shipment receipt.
