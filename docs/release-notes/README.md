# Release notes

Per-version ship notes live here as `RELEASE_NOTES_v*.md` (workspace copy of what accompanies releases; older versions remain for history).

- **Current version** has one authority: `.claude-plugin/plugin.json`. `CHANGELOG.md` and these notes are historical records of releases, not current-version authorities.
- **Archive membership** is determined by the release builders and must be verified from the resulting archive. Do not infer the shipped member set from this directory index.
